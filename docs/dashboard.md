
# Web Dashboard

## 1. Overview

The Raspberry Pi Health Monitor includes a lightweight web dashboard developed with Python.

It provides a read-only web interface to visualize the latest monitoring report from the Raspberry Pi.

The dashboard runs as a systemd service and is accessible from devices connected to the same local network.

## 2. Features

- Displays the overall system health status.
- Shows CPU load and RAM usage.
- Displays disk usage and CPU temperature.
- Shows the number of failed systemd services.
- Displays system uptime.
- Automatically refreshes the page every 60 seconds.
- Uses the latest Markdown report generated by the monitoring script.
- Read-only interface: it does not modify system resources or reports.

## 3. Requirements

- Raspberry Pi running Ubuntu Server.
- Python 3.
- Existing Raspberry Pi Health Monitor installation.
- A local network connection.

No external Python packages are required.

## 4. Dashboard Installation

The dashboard files are located in:

```text
dashboard/
├── health-dashboard.py
└── systemd-health-dashboard.service
```

Make sure the project is available at:

```text
/home/ubuntu/raspberry-pi-health-monitor
```

## 5. Configure the Service

Edit the systemd service file:

```bash
sudo nano /etc/systemd/system/systemd-health-dashboard.service
```

Configure the execution command using the Raspberry Pi's private IP address:

```ini
ExecStart=/usr/bin/python3 /home/ubuntu/raspberry-pi-health-monitor/dashboard/health-dashboard.py --host YOUR_PI_IP --port 8080
```

Replace `YOUR_PI_IP` with the Raspberry Pi's actual local IP address.

## 6. Enable the Service

Reload systemd:

```bash
sudo systemctl daemon-reload
```

Enable and start the dashboard:

```bash
sudo systemctl enable --now systemd-health-dashboard.service
```

Check the service status:

```bash
sudo systemctl status systemd-health-dashboard.service
```

The expected state is:

```text
Active: active (running)
```

## 7. Access the Dashboard

Open a web browser from a device connected to the same local network.

Navigate to:

```text
http://YOUR_PI_IP:8080/
```

Replace `YOUR_PI_IP` with the Raspberry Pi's local IP address.

## 8. Useful Commands

Check the dashboard service:

```bash
sudo systemctl status systemd-health-dashboard.service
```

Restart the dashboard:

```bash
sudo systemctl restart systemd-health-dashboard.service
```

Stop the dashboard:

```bash
sudo systemctl stop systemd-health-dashboard.service
```

View service logs:

```bash
sudo journalctl -u systemd-health-dashboard.service -n 50
```

## 9. Security

- The dashboard is read-only.
- It does not execute system commands through HTTP requests.
- It uses a specific private IPv4 address instead of listening on all network interfaces.
- It includes HTTP security headers.
- It does not implement authentication.

The dashboard should only be used on a trusted local network.

Do not expose port 8080 directly to the public Internet.
